# 🐍 Python for Generative AI

Welcome to my **30-Day Python Learning Journey!** 🚀

I am learning Python specifically to build a strong foundation in **Generative AI (GenAI)**. My goal is to understand the Python concepts required to develop AI-powered applications and work with Large Language Models (LLMs).

This repository contains my daily practice code, exercises, notes, and mini-projects throughout this journey.

- Understand Python data structures and functions.
- Learn API integration and asynchronous programming.

- Understand LLM APIs and prompt engineering.

- Build practical Generative AI applications.
